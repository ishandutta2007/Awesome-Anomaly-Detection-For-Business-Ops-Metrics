### 📌 Overview & SEO Summary 🔍 ✨

Welcome to the definitive, search-optimized curated directory of **anomaly detection platforms for business and operational metrics**, **open-source time-series outlier detection libraries**, and **AIOps monitoring frameworks** 🌐.

Modern engineering and revenue teams rely on automated metric monitoring to detect unexpected drops in revenue, latency spikes, conversion anomalies, and data quality degradation 🛡️. This repository provides a comprehensive comparison across category-leading commercial SaaS platforms (such as *Amazon Lookout for Metrics*, *Datadog Watchdog*, *Dynatrace Davis AI*, *Scale AI Outlier*, and *Monte Carlo Data*) alongside battle-tested open-source libraries (like *Prophet*, *Darts*, *PyOD*, *Kats*, *Merlion*, *STUMPY*, *ADTK*, *Anomstack*, and *Luminol*) ⚡.

Key evaluation vectors include:
- 🎯 **Business Metric & KPI Monitoring**: Detecting seasonal spikes, mean shifts, level shifts, and variance changes in key operational metrics.
- ⏱️ **Time-Series Forecasting & Change Point Detection**: Unsupervised ML models for univariate and multivariate metrics data.
- 🤖 **AIOps & Root Cause Analysis (RCA)**: Automated event correlation, topological dependency tracing, and automated incident alerting.
- 🔐 **Self-Hosted & Privacy-Preserving Stacks**: Open-source pipelines to process sensitive internal telemetry without third-party vendor lock-in.

## 🔓 Open-Source GitHub Projects 🔓 🛠️

*Sorted by GitHub Stars Count (Descending)* 🌟 ⭐

- **[Prophet](https://github.com/facebook/prophet)** [![Stars](https://img.shields.io/github/stars/facebook/prophet?style=social&color=white)](https://github.com/facebook/prophet/stargazers) 📈  
  **Automatic forecasting & anomaly detection procedure by Meta**, MIT licensed. ~16,000+ stars ⭐. Highly robust to missing data, trend shifts, and large outliers. Widely used to establish baseline KPI expectations and spot metric anomalies.

- **[Darts](https://github.com/unit8co/darts)** [![Stars](https://img.shields.io/github/stars/unit8co/darts?style=social&color=white)](https://github.com/unit8co/darts/stargazers) 🎯  
  **User-friendly Python library for time-series forecasting & anomaly detection**, Apache-2.0 licensed. ~9,500+ stars ⭐. Unified API for ARIMA, N-BEATS, Transformer, and PyTorch models with built-in anomaly detection evaluators.

- **[PyOD (Python Outlier Detection)](https://github.com/yzhao062/pyod)** [![Stars](https://img.shields.io/github/stars/yzhao062/pyod?style=social&color=white)](https://github.com/yzhao062/pyod/stargazers) 🐍  
  **Comprehensive Python toolkit for outlier detection**, BSD-2-Clause licensed. ~8,000+ stars ⭐. 50+ detection algorithms including Isolation Forest, LOF, KNN, AutoEncoder, and COPOD. The foundational library for building custom anomaly detection pipelines.

- **[Kats](https://github.com/facebookresearch/Kats)** [![Stars](https://img.shields.io/github/stars/facebookresearch/Kats?style=social&color=white)](https://github.com/facebookresearch/Kats/stargazers) 📊  
  **Facebook's time-series analysis toolkit**, MIT licensed. ~5,500+ stars ⭐. Forecasting, detection (CUSUM, Prophet, multivariate anomaly detection), and feature extraction for operational metric workflows.

- **[Merlion](https://github.com/salesforce/Merlion)** [![Stars](https://img.shields.io/github/stars/salesforce/Merlion?style=social&color=white)](https://github.com/salesforce/Merlion/stargazers) 🦁  
  **Time-series intelligence library by Salesforce**, BSD-3-Clause licensed. ~4,000+ stars ⭐. Unified framework for forecasting, anomaly detection, and change point detection with 20+ models (AutoARIMA, Prophet, Isolation Forest, Spectral Residual).

- **[STUMPY](https://github.com/TDAmeritrade/stumpy)** [![Stars](https://img.shields.io/github/stars/TDAmeritrade/stumpy?style=social&color=white)](https://github.com/TDAmeritrade/stumpy/stargazers) ⚡  
  **Scalable time-series matrix profile computation**, BSD-3-Clause licensed. ~3,500+ stars ⭐. Fast discovery of motifs (repeating patterns) and discords (anomalies) in time-series data with GPU acceleration support.

- **[ruptures](https://github.com/deepcharles/ruptures)** [![Stars](https://img.shields.io/github/stars/deepcharles/ruptures?style=social&color=white)](https://github.com/deepcharles/ruptures/stargazers) ✂️  
  **Python library for change point detection**, BSD-2-Clause licensed. ~3,000+ stars ⭐. Detects mean shifts, variance changes, and trend breaks in business metrics (Pelt, Binseg, BottomUp, Window).

- **[Alibi Detect](https://github.com/SeldonIO/alibi-detect)** [![Stars](https://img.shields.io/github/stars/SeldonIO/alibi-detect?style=social&color=white)](https://github.com/SeldonIO/alibi-detect/stargazers) 🛡️  
  **Algorithms for outlier, adversarial, and drift detection**, Apache-2.0 licensed. ~2,500+ stars ⭐. Online and offline detectors for tabular, text, image, and time-series metrics.

- **[Telemanom (NASA)](https://github.com/khundman/telemanom)** [![Stars](https://img.shields.io/github/stars/khundman/telemanom?style=social&color=white)](https://github.com/khundman/telemanom/stargazers) 🚀  
  **LSTM-based anomaly detection for spacecraft telemetry**, MIT licensed. ~2,000+ stars ⭐. Nonparametric, unsupervised approach for detecting anomalies in multivariate time-series without labeled data.

- **[ADTK (Anomaly Detection Toolkit)](https://github.com/arundo/adtk)** [![Stars](https://img.shields.io/github/stars/arundo/adtk?style=social&color=white)](https://github.com/arundo/adtk/stargazers) 🛠️  
  **Python toolkit for unsupervised time-series anomaly detection**, MPL-2.0 licensed. ~1,500+ stars ⭐. Built for business and ops metrics with detectors like InterQuartileRange, LevelShift, VolatilityShift, and Persist.

- **[Luminol](https://github.com/linkedin/luminol)** [![Stars](https://img.shields.io/github/stars/linkedin/luminol?style=social&color=white)](https://github.com/linkedin/luminol/stargazers) 💡  
  **Lightweight anomaly detection and correlation library by LinkedIn**, Apache-2.0 licensed. ~1,100+ stars ⭐. Algorithms include Bitmap, Derivative, and ExponentialMovingAverage with cross-metric correlator for root cause triage.

- **[TSB-AD](https://github.com/thedatumorg/TSB-AD)** [![Stars](https://img.shields.io/github/stars/thedatumorg/TSB-AD?style=social&color=white)](https://github.com/thedatumorg/TSB-AD/stargazers) 🧪  
  **Time-Series Anomaly Detection Benchmark Framework**, MIT licensed. ~335 stars ⭐. Standardized evaluation suite with 40+ algorithms and 1,000+ time-series datasets for objective benchmarking.

- **[Anomstack](https://github.com/andrewm4894/anomstack)** [![Stars](https://img.shields.io/github/stars/andrewm4894/anomstack?style=social&color=white)](https://github.com/andrewm4894/anomstack/stargazers) 📦  
  **Painless open-source anomaly detection for metrics**, MIT licensed. ~114 stars ⭐. End-to-end pipeline: SQL/API ingestion, anomaly detection (PyOD/Prophet), Slack/email alerting, FastHTML dashboarding, and Dagster orchestration.

- **[Prometheus Anomaly Detection (LSTM Autoencoder)](https://github.com/vpuhoff/prometheus-anomaly-detection-lstm)** [![Stars](https://img.shields.io/github/stars/vpuhoff/prometheus-anomaly-detection-lstm?style=social&color=white)](https://github.com/vpuhoff/prometheus-anomaly-detection-lstm/stargazers) 🤖  
  **LSTM autoencoder for Prometheus time-series anomaly detection**, MIT licensed. ~50+ stars ⭐. Collects PromQL metrics, trains neural network, detects anomalies, and exposes metrics via Prometheus exporter.

- **[Random Cut Forest (AWS)](https://github.com/aws/random-cut-forest-by-aws)** [![Stars](https://img.shields.io/github/stars/aws/random-cut-forest-by-aws?style=social&color=white)](https://github.com/aws/random-cut-forest-by-aws/stargazers) 🌲  
  **AWS's Random Cut Forest algorithm for anomaly detection**, Apache-2.0 licensed. ~50+ stars ⭐. Streaming-friendly unsupervised algorithm powering Amazon Lookout for Metrics and SageMaker RCF.

- **[Orion](https://github.com/sintel-dev/Orion)** [![Stars](https://img.shields.io/github/stars/sintel-dev/Orion?style=social&color=white)](https://github.com/sintel-dev/Orion/stargazers) 🌌  
  **Machine learning library for unsupervised time-series anomaly detection**, MIT licensed. ~40+ stars ⭐. Automates pipeline selection and hyperparameter tuning across 20+ primitive time-series pipelines.
